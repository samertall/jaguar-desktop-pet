# Jaguar Desktop Pet — Privacy Policy

**Effective date:** November 15, 2026  
**Developer:** Samer Tallauze  
**Application:** Jaguar Desktop Pet (Windows desktop application)  
**Website:** https://samertall.com

## Summary

Jaguar Desktop Pet is an offline animated desktop companion. The current Windows build does **not** contain advertising, analytics, user accounts, web requests, or cloud synchronization. It does not transmit personal information to the developer or third parties.

## Information the app accesses

To display and control the jaguar, the app uses Windows desktop functionality such as the work area (screen size and taskbar bounds), the tray menu, and keyboard shortcuts. The cursor position is used when opening the tray menu. These operations are performed locally.

## Local diagnostic logs

The app writes a technical troubleshooting log on your own computer:

`%LOCALAPPDATA%\JaguarDesktopPet\jaguar.log`

The log may contain timestamps, executable paths, process identifiers, animation state, window events and rendering errors. These records remain on your device; the app does not upload them or share them with the developer. You can delete the log file when the app is closed.

## Data collection, sharing and retention

- **Personal data collected by the developer:** None through the app.
- **Information transmitted from the app:** None.
- **Advertising or third-party analytics:** None.
- **Data stored locally:** Only the technical diagnostic log described above.
- **Data retention:** Local logs remain until manually deleted; the app does not automatically upload or centrally retain logs.
- **Accounts and purchases:** Not required; no in-app purchases.

## Children

The application is a desktop customization tool. It does not knowingly collect information from children or adults.

## Security

The app uses Windows desktop APIs and does not request access to your camera, microphone, contacts or location. Its MSIX package declares the Windows full-trust capability needed by the desktop overlay.

## Updates to this policy

If future releases introduce cloud services, telemetry, accounts or other data-processing features, this policy will be updated before the relevant release.

## Contact

For questions about Jaguar Desktop Pet or this policy, visit **https://samertall.com**.
